# IA ética + legal: decidir con criterio

Sitio estático para una sesión final de dos horas sobre decisiones responsables al usar IA generativa en contexto universitario y administrativo.

## Ruta de 90 minutos

1. Brújula ética: dignidad, equidad, privacidad, trazabilidad y responsabilidad.
2. Autoría y trazabilidad: el caso de la selfie del macaco como detonante.
3. Datos y privacidad: qué viaja en un prompt y a qué proveedor.
4. Riesgo y supervisión humana.
5. Compras responsables y gobernanza.
6. Taller de decisión aplicado a tres escenarios administrativos.

Los 30 minutos restantes están reservados para conversación, preguntas y discusión de los casos.

## Material descargable

- assets/ejemplos/lista-decision-ia.md: lista breve para evaluar un uso de IA.
- assets/ejemplos/ficha-decision-ia.md: ficha de trabajo para la actividad final.

## Aviso importante

El material es educativo, no asesoría jurídica. Los casos reales con datos personales, decisiones de alto impacto o contratación de proveedores requieren consulta con las áreas institucionales correspondientes.
