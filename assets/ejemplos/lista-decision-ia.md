# Lista breve para decidir sobre un uso de IA

> Esta lista orienta una conversación de trabajo. No reemplaza la revisión jurídica, de privacidad, seguridad o cumplimiento cuando el caso lo requiere.

## 1. Finalidad

- ¿Qué problema concreto se busca resolver?
- ¿Qué beneficio esperamos y para quién?
- ¿La IA es proporcional o existe una alternativa más simple?

## 2. Personas y datos

- ¿Quiénes pueden verse afectados por la decisión o la salida?
- ¿Qué datos se procesarán?
- ¿Hay datos personales, sensibles, financieros, contractuales o confidenciales?
- ¿Podemos anonimizar, minimizar o usar datos sintéticos?

## 3. Riesgos y salvaguardas

- ¿Qué daño podría producir un error, sesgo, filtración o uso indebido?
- ¿Quién revisa y puede corregir el resultado antes de actuar?
- ¿Cómo se informa y se permite cuestionar una decisión relevante?
- ¿Qué evidencia o registro debemos conservar?

## 4. Proveedor y condiciones

- ¿Dónde se procesan y almacenan los datos?
- ¿El proveedor usa nuestros datos para entrenar modelos?
- ¿Qué ocurre con los datos y el acceso al terminar el contrato?
- ¿Qué controles de seguridad, auditoría y reporte de incidentes existen?

## 5. Decisión

- [ ] Avanzar: riesgo bajo y controles suficientes.
- [ ] Avanzar con condiciones: faltan salvaguardas, revisión o autorización.
- [ ] Detener y escalar: el uso involucra alto impacto, datos sensibles o una decisión relevante sobre personas.
